# Installation

This guide covers how to install and set up the Godot-LiveKit GDExtension in your project.

## Prerequisites

To build the extension from source, you will need:

- **Python 3.x**
- **SCons** (`pip install scons`)
- **CMake** (Optional, for advanced builds)

**Platform-Specific Requirements:**
- **Linux:** `g++`, `curl`, `tar`, `unzip`
- **macOS:** Xcode Command Line Tools, `curl`, `tar`, `unzip`
- **Windows:** MSVC (Visual Studio Build Tools), run from Git Bash. Cross-compiling from Linux with MinGW-w64 is not supported, because the prebuilt LiveKit C++ SDK for Windows is built with MSVC and its C++ ABI is incompatible with MinGW.
- **Android:** Android NDK (r26d is used in CI) with `ANDROID_NDK_ROOT` or `ANDROID_NDK_HOME` set, plus `curl`, `tar`, `unzip`

## Building from Source

This repository includes a custom `build.sh` script that automatically fetches the prebuilt LiveKit C++ SDK, builds `godot-cpp` from source (once; the result is cached in `godot-cpp/`), and compiles the extension.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NodotProject/godot-livekit.git
   cd godot-livekit
   ```

2. **Run the build script for your platform:**

   - **Linux:**
     ```bash
     ./build.sh linux
     ```
   - **macOS:**
     ```bash
     ./build.sh macos
     ```
   - **Windows:**
     ```bash
     ./build.sh windows
     ```
   - **Android (arm64):**
     ```bash
     ./build.sh android
     ```

   Add `--debug` to build the `template_debug` variant, or `--double --api-file=extension_api.json` to build for a double-precision Godot build (`precision=double`), where `extension_api.json` is generated by your double-precision Godot binary with `godot --dump-extension-api`. Double-precision libraries are named `libgodot-livekit.<platform>.double.<arch>` and are picked up automatically by double-precision Godot builds.

Once the build is complete, the compiled dynamic libraries (`.so`, `.dylib`, or `.dll`) and the LiveKit shared libraries will be placed in the `addons/godot-livekit/bin/` directory.

## Installation in Godot

Once you have built the extension from source, or downloaded a pre-built release:

1. Copy the `addons/godot-livekit` folder into your Godot project's `addons/` directory.
2. Enable the plugin from the Godot Editor: **Project -> Project Settings -> Plugins**.

### Android

On Android, WebRTC does all microphone and speaker I/O through its `org.webrtc` Java classes, so they must be included in your app or it aborts when connecting to a room. They are shipped as `addons/godot-livekit/bin/android-arm64/libwebrtc.jar`. To include them:

1. Install the Android build template: **Project -> Install Android Build Template**.
2. Copy `libwebrtc.jar` into `android/build/libs/debug/` and `android/build/libs/release/`.
3. Enable **Use Gradle Build** in your Android export preset, along with the `RECORD_AUDIO`, `MODIFY_AUDIO_SETTINGS` and `INTERNET` permissions.

You are now ready to start using LiveKit in your Godot project. Proceed to the [Quickstart](quickstart) guide to see how to connect to a room.
